## 0. Règles de travail (à respecter pendant toute la correction)

- **Plateforme unique** : Windows 10/11, Edge/Chrome (Chromium récent), lancé en fenêtre `--app`.
  API Chromium modernes autorisées sans polyfill ni préfixe. Pas de Safari/Firefox/mobile.
- **Stack** : HTML5, CSS3, JS ES2023+ en modules ES natifs. Firebase **SDK modulaire** uniquement.
- **Aucune dépendance npm à l'exécution**, pas de bundler : l'app est servie telle quelle par GitHub Pages.
- **Ne jamais perdre de données** : avant toute opération qui écrase ou migre des données,
  proposer un export JSON (`exportAdminBackup`).
- **Après chaque correction** :
  1. ajouter une ligne dans le tableau « Historique des mises à jour » de `README.md` ;
  2. dans `Problème rencontrés.md`, passer le point concerné (A1…A16) en **Statut : corrigé le AAAA-MM-JJ**
     avec une ligne « Correction appliquée » ; y ajouter tout nouveau problème rencontré + sa solution ;
  3. cocher la case correspondante dans ce fichier ;
  4. un commit par correction, message en français : `fix(A5): accordéons non tronqués`.
- Ne pas toucher aux clés, tokens ni à `FIREBASE_CONFIG`.
- Tester dans Chromium (Playwright headless accepté) à **1200×800** et **800×533** (= 150 % de mise à l'échelle).
